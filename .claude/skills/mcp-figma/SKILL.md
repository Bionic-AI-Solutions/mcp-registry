# Figma MCP

Use the **figma** MCP server when the task involves:

- Reading or inspecting Figma files, frames, or components
- Extracting design tokens, assets, or layout data from Figma
- Syncing design specs with code or documentation

Use the exact tool names and parameters exposed by the Figma MCP server.
