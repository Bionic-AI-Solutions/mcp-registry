# Archon MCP

Use the **archon** MCP server when the task involves:

- Searching external knowledge bases or indexed content outside this repo
- Research or "find information about X" when the source is not project docs

**Do not** use Archon for project-internal docs. Use indexed docs or Context7 for library/framework docs.
