# OpenProject MCP

Use the **openproject** MCP server when the task involves:

- Creating or updating work packages, tasks, stories, epics
- Storing or retrieving project documents in OpenProject
- Querying project status, assignees, or timelines

Pass the correct `tenant_id` and use exact tool names from the MCP server.
