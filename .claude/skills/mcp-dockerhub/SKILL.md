# Docker Hub MCP

Use the **dockerhub** MCP server when the task involves:

- Searching Docker Hub for official or community images
- Checking image tags, descriptions, or pull counts
- Deciding which image to use in Dockerfiles or docker-compose

Use the MCP tools instead of manual browser search.
