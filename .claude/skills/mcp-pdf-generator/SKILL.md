# PDF Generator MCP

Use the **pdf-generator** MCP server when the task involves:

- Generating PDFs from HTML, text, or templates
- Fetching or downloading generated PDF files

## Tool naming (do not guess)

- **Prefix:** `pdf_*`
- **Correct:** `pdf_generate_pdf`, `pdf_get_pdf_file`
- **Wrong:** `generate_pdf`, `create_pdf`, `get_pdf`

Use exact tool names from the MCP server.
