# n8n MCP

Use the **n8n-mcp** MCP server when the task involves:

- Triggering or querying n8n workflows from the agent
- Listing workflows, executions, or nodes
- Integrating n8n automation into development or ops tasks

Use exact tool names from the MCP server. API URL and key are configured in the MCP environment.
