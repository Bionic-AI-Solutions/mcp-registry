# FFmpeg MCP

Use the **ffmpeg** MCP server when the task involves:

- Transcoding, converting, or processing video or audio
- Extracting streams, thumbnails, or metadata from media
- Applying FFmpeg-based filters, codecs, or container formats

Use the exact tool names and parameters exposed by the FFmpeg MCP server.
