# Meilisearch MCP

Use the **meilisearch** MCP server when the task involves:

- Indexing documents or records for full-text search
- Running search queries, faceted search, or typo tolerance
- Managing indexes, ranking rules, or stop words per tenant

Pass the correct `tenant_id` and use exact tool names from the MCP server.
