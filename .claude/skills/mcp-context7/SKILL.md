# Context7 MCP

Use the **context7** MCP server when the task involves:

- Looking up latest docs for libraries, frameworks, or languages
- Verifying API signatures, config options, or migration guides
- Resolving "how does X work in library Y?" questions

Use indexed project docs first, then Context7, then web search.
