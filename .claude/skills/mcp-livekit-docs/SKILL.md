# LiveKit Docs MCP

Use the **livekit-docs** MCP server when the task involves:

- LiveKit SDK, WebRTC, agents, or room/participant APIs
- Implementing live streaming, recording, or egress with LiveKit
- Integrating LiveKit with React, Flutter, or server SDKs

Query LiveKit docs via this MCP instead of guessing APIs.
